# Salmon Isle 2.2.0

新增行内文字颜色、荧光背景和自定义 HEX 配色，自动适配日间与深色模式。源码、可视化编辑、预览与复制粘贴使用同一语法。

页面编辑器改为 HTML、CSS、预览标签页，提供页面专用工具栏、图片与动态内容插入菜单，设置侧栏精简为地址、权限、别名和适用页面的评论关联值。文章展示设置移到侧栏顶部，文件夹选择按完整路径排序。

归档目录和分页支持无刷新导航并保持目录状态。阅读侧栏以 1200px 为自动停靠断点，宽度随屏幕收窄，每篇文章重新判断开关。调整窄屏目录边框、状态标签和卡片操作间距；所有留言区域移除原标题行。

字体和内置静态图片支持长期浏览器缓存；文章图片新增权限校验后的 ETag / Last-Modified 条件响应，减少重复下载。导入／导出页面统一现有 WordPress 导入、内容导出和整站备份入口。

数据格式继续兼容 2.1，无需内容迁移。升级操作见 [2.2 升级指南](upgrade-2.2.zh-CN.md)。
