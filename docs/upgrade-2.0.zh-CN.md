# 升级到 Salmon Isle 2.0

先升级网站，再升级电脑客户端。现有文章、页面、图片、权限和回收站会保留；原 Git 内容库和历史不会被清空。

## 1. 网站

在现有 Docker 部署目录中执行：

```sh
sh scripts/update-site.sh --image ghcr.io/duguiyu07/salmon-isle:2.0.5
```

Windows Docker 主机使用：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/update-site.ps1 -Image ghcr.io/duguiyu07/salmon-isle:2.0.5
```

首次跨版本升级请先下载本次 Release 的服务器包，把包内 scripts/update-site.sh（Windows 使用源码包中的 update-site.ps1）覆盖到部署目录的 scripts/，再运行上面的命令。服务器包不包含个人内容。

脚本先下载程序镜像，再停止网站并备份 data。新程序首次启动会将内容转换到 data/library-v2，保留正在公开的文章，并把未发布改动保留为草稿。迁移前原数据副本保存在 data/backups/before-2.0-*。健康检查失败时脚本恢复原数据和旧镜像。升级备份位于部署目录的 backups/program-*。

迁移成功后，在线后台的“同步”中可以查看或撤销写入设备。内容编辑使用桌面客户端，网站后台继续提供设置、查看、导出和备份。

## 2. 电脑客户端

优先打开旧客户端右上角“更新”，依次选择“检查更新”“下载更新”“保存并重启安装”。

如果旧版无法启动、更新源不可用或使用 ZIP 版：

1. 从本次 Release 下载 Salmon-Isle-Writer-2.0.5-x64.exe。
2. 退出旧版，直接运行新版安装程序，选择原安装位置覆盖安装。
3. 无需先卸载。程序标识及用户数据目录保持一致，原本地内容、恢复稿和更新配置会保留。

ZIP 版可解压到新目录运行，请勿删除原用户数据目录。

## 3. 重新连接一次

新版客户端打开“同步”，填写网站 HTTPS 地址和原管理密码。如果已有写入设备，确认需要替换后勾选“替换已有写入设备”。密码不会保存在本机，设备凭证使用系统加密存储。

首次连接以网站数据为准；连接前的本地内容完整保存在恢复目录。同步页的“导入为恢复草稿”可将独有或不同的本地文字导入独立文件夹，不会自动发布。确认恢复内容后再正常发布。

草稿自动保存到本机并同步；发布、更新和撤回需要联网。断网继续写作，退出重启也会保留队列。目录调整和回收站操作确认后，联网时自动应用到网站。

## 回退与恢复

保留升级脚本生成的备份。回退 1.x 时先停止写入，恢复升级前数据并使用升级前镜像。2.0 中新增的内容不会自动写回旧 Git 库，应先导出或备份。

恢复 2.0 整站备份后，旧设备凭证会失效，需要重新连接，防止旧离线队列覆盖恢复后的内容。
