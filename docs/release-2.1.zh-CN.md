# Salmon Isle 2.1.0

所有管理功能回归网站：文章与 HTML/CSS 页面编辑、媒体库、文件夹、回收站、WordPress 导入、预览、导出和备份。桌面端及同步入口停用，旧客户端不能写入网站。

WordPress 导入整合到设置中，顶部导航保留文章、页面、媒体库和设置。后台导航与编辑链接支持中键打开新标签页；编辑地址可复制、刷新并前进后退。未保存恢复稿按文档和会话隔离。文章状态移到标题左侧并区分颜色，后台文章卡片去掉概要，工具栏按功能分组。

文章支持批量移动、权限、发布／更新和撤回。批量操作有版本检查与整批回滚；目录和权限立即生效，正文编辑稿保留。统一密码保护可一次设置。批量发布包括最新保存的编辑稿。

后台默认列表改为“最近修改”，包含已保存编辑稿的修改时间。前台 Index 收录全部非 MISC 的可见已发布文章，默认按创建时间倒序，正常编辑不再依赖手动重建索引。

编辑页标题上方新增退出编辑链接；侧栏按钮缩短为保存、预览、全屏，摘要、封面和置顶整合到展示设置，封面支持媒体库、上传和 URL，排序权重移入高级设置。

网站数据格式沿用 2.0，升级前备份并按 [2.1 升级指南](upgrade-2.1.zh-CN.md) 操作。发布仅提供网站镜像、源码包、服务器包和校验文件。
