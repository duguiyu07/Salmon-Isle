# Salmon Isle 2.0.3

内容同步改为客户端直接连接网站。写作自动保存，草稿自动同步，点击发布后上线；断网和重启保留本地工作，不再需要仓库、分支、提交或推送。

编辑器统一了选区工具栏图标、区块设置栏宽度和输入高度，增加完整段落/列表项的移动、删除及快捷组合，支持嵌套内容组。公式删除了重复编辑弹窗，图片说明改为在图片下方原位编辑。修复了删除内联 Markdown 后方文字时连带删除结束符的问题。

**升级顺序：先网站，再客户端。** 完整步骤请阅读本 Release 附带的《升级到2.0.md》。客户端可通过应用内更新，或下载安装包直接覆盖安装，无需卸载。服务器升级脚本会备份并执行迁移，启动失败时恢复旧数据与镜像。

网站当前线上内容作为迁移基准，未发布改动保留为草稿。旧客户端独有内容可以在同步页导入为恢复草稿。原 Git 内容及历史保留在迁移前备份中。
