# 升级到 Salmon Isle 2.2.1

升级前在后台“设置 → 导入／导出”下载整站备份；旧版本的整站备份入口位于设置页。保留服务器的环境配置和数据目录。

先从本版本服务器包更新 `scripts/` 中的更新与清理脚本，沿用现有 Compose、环境配置、端口和代理。使用 `sh scripts/update-site.sh --image ghcr.io/duguiyu07/salmon-isle:2.2.1` 更新。源码部署使用 Node.js 24，重新安装依赖、构建并启动。首次打开后台后刷新页面以加载新版界面。2.1／2.2 的文章、页面、媒体与编辑稿均可直接继续使用，无需内容迁移；从更早版本升级时先遵循 [2.1 升级指南](upgrade-2.1.zh-CN.md)。

升级脚本在启动检查成功后默认清理临时程序备份、已废弃的内容快照和没有容器引用的本站旧镜像。当前 `library-v2` 中的正文、最新编辑稿、媒体与回收站继续保留。升级前务必将整站备份下载到自己的电脑。

需要在成功启动后进一步人工验收时，更新命令添加 `--retain-backup`；验收结束执行 `sh scripts/cleanup-site.sh`。Windows 对应 `-RetainBackup` 和 `scripts/cleanup-site.ps1`。更新失败时保留回退材料并尝试恢复旧数据、配置和镜像；核实恢复后再处理备份。清理只适用于已经完成 2.x 内容库迁移的站点。

字体文件与内置图片按资源版本缓存，版本更新会自动使用新的资源地址。文章图片保留权限验证，未变化时返回 304 并复用浏览器本地文件。无需手动清除浏览器缓存。

新增 `:text[文字]{color="red" background="yellow"}` 语法。自定义 HEX 自动配对两个主题；使用新语法后回退旧程序可能显示原始标记，回退前请保留备份。

发布仍沿用网站镜像、源码包、服务器包及校验文件；服务器更新脚本和数据目录路径保持原有用法。
